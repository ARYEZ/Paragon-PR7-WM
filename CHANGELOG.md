# Changelog

## 0.1.0

- First release: file and folder compare that works the way WinMerge works.
- File compare: lined-up texts, changed words marked, the location pane and the Diff pane; Copy to Right / Left, Copy
  All, typing in either side, Undo / Redo, saving that keeps each file's encoding and line endings.
- WinMerge's options: whitespace, blank lines, case, carriage return differences, word or character marks.
- Folder compare: five compare methods, filter masks, show choices, copy and delete (to the Recycle Bin).
- Generate Patch, Find, Go To, reload when a file changes elsewhere, binary files.
- "Compare in PR7-WM" in Explorer's menu (two items, or one now and one later) and WinMerge's command line.
- OBSIDIAN and AURORA finishes (one choice for the whole family), Check for Updates.
